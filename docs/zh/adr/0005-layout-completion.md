# ADR-0005: 1D Flexbox 布局实现完成

## 状态
已接受

## 上下文
ADR-0001 选择了一维 flexbox 布局引擎，但未实现它。我们需要交付
该包，以便应用程序可以立即构建组件树，同时保持 AGENTS.md §7
中的零分配契约。

## 决策
`layout` 包根据 ADR-0001 实现了 `Container`、`Leaf` 和 `Child`
类型，具有三个整数布局属性（`Basis`、`Grow`、`Shrink`）和两个
方向（`Row`、`Column`）。

三个算法规则控制分布：

1. **阶段 1 — Basis**：每个 `Basis > 0` 的子节点在主轴上获得精确
   该大小；剩余总和被累加。
2. **阶段 2 — Grow / Shrink**：剩余空间按 `Grow` 分配，或溢出按
   `Shrink` 吸收。整数舍入余数按每次一个单位分配给首个合格的子
   节点。
3. **阶段 3 — 布局**：每个子节点沿主轴定位；最后一个子节点吸收
   任何舍入残差，使得 `sum(child main sizes) == available`。

零分配需要为每个容器栈分配子节点大小的暂存缓冲区。缓冲区保存
256 个条目；更深的容器回退到 `measureSlow` 中的一次性堆分配。
交叉轴大小原样传递（Row 子节点都获得父级高度；Column 子节点都
获得父级宽度）。

## 依据

- CSS flexbox 心智模型最大限度地降低了新贡献者的学习曲线。
- 三阶段算法对每个容器为 O(N)，可手动轻松验证。
- 预分配结果切片并通过递归传递，使热路径保持在 0 B/op、
  0 allocs/op（已通过基准验证）。

## 影响

- 多轴网格需要嵌套（Row → Column → Row …）— 与规范已接受的权衡
  相同。
- `measureSlow` 对宽于 256 个子节点的容器分配一次；在实践中，
  这在 TUI 树上从不触发。
- `Child.Node` 字段是可选的；`nil` 生成布局矩形而不进行递归。
