# ADR-0001: 类 Flexbox 布局系统

## 状态
已接受

## 上下文
TUI 引擎需要布局系统来确定组件在终端网格中的位置与大小。评估了三种方案：类 Flexbox、基于约束 (Cassowary) 以及混合方案。

## 决策
**类 Flexbox** — 沿主轴/交叉轴的一维空间分配，具备 grow、shrink 和 basis 属性。二维布局通过行 (row) 和列 (col) 容器嵌套构成。

## 依据
- 行为可预测，Web 开发者熟悉。
- 覆盖 ≥90% 的 TUI 布局场景。
- 计算速度快于约束求解器 — 对零分配渲染热路径至关重要。
- 实现简单，易于调试。

## 影响
- 复杂的网格布局需要嵌套，增加组件树深度。
- 实现位于 `layout/` 包中。
