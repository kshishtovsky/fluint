# ADR-0002: 组合式终端能力检测

## 状态
已接受

## 上下文
引擎必须检测终端支持的特性（色彩深度、同步输出、kitty 键盘协议）。检测策略影响启动延迟与可靠性。

## 决策
**组合式 (Combo)** — 环境变量 (`$TERM`, `$COLORTERM`, `$TERM_PROGRAM`) 提供基础检测；主动 ANSI 查询 (DECRQM mode 2026, DA1) 获取高级特性，附带超时与保守回退。

## 依据
- 环境变量零 I/O、零延迟。
- 主动查询能准确获取环境变量常遗漏的真实能力。
- 超时 + 回退机制保障管道与无响应终端下的健壮性。

## 影响
- 双重检测代码路径。
- 实现位于 `internal/term/caps.go` 的 `Detect()` 与 `DetectActive()`。
