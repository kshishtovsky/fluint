# Журнал изменений (Changelog)

Все заметные изменения в этом проекте будут документироваться в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и проект придерживается [семантического версионирования](https://semver.org/lang/ru/spec/v2.0.0.html).

## [v0.2.0] - 2026-07-28

### Добавлено
- Пакет `anim`: функции сглаживания (`EaseFunc`) с 9 именованными кривыми — `Linear`, `InQuad`, `OutQuad`, `InOutQuad`, `InCubic`, `OutCubic`, `InOutCubic`, `OutBounce`, `OutElastic` — на основе пакетных функций (не замыканий) для использования на горячем пути без аллокаций. Только `OutElastic` использует `math.Pow`; все остальные кривые — только арифметика.
- Пакет `core/buffer`: метод `Buffer.SetSubCellY(x, y, ySub int, color uint32)` для вертикального субпиксельного рендеринга с использованием Unicode-символов половинных блоков (`▀` U+2580, `▄` U+2584). Удваивает вертикальное разрешение без дополнительной памяти за счёт повторного использования существующих полей `Cell.Fg`/`Cell.Bg`.
- ADR-0006: запись архитектурного решения по субпиксельному рендерингу и функциям сглаживания.

## [v0.4.0] - 2026-07-28

### Добавлено
- Пакет `widgets`: базовая система виджетов с API функциональных опций (ADR-0004). Включает интерфейс `Node`, общую структуру `Config` и тип функциональных опций `Option` с хелперами (`WithWidth`, `WithHeight`, `WithForeground`, `WithBackground`, `WithBold`, `WithItalic`, `WithUnderline`, `WithDim`, `WithStrikethrough`, `WithReverse`, `WithOnPress`).
- Пакет `widgets`: виджет `Text` для рендеринга однострочного текста с обрезкой, поддержкой цвета и атрибутов. Рендеринг без аллокаций.
- Пакет `widgets`: виджет `Button` с центрированной меткой, заливкой фона всего прямоугольника и коллбэком `Press()`. Рендеринг без аллокаций (0 allocs/op, ~193 ns/op).
- Git pre-commit хук (`.git/hooks/pre-commit`), запускающий `go test -race ./...` и `golangci-lint run ./...` перед каждым коммитом.

## [v0.3.0] - 2026-07-28

### Добавлено
- Пакет `anim`: система `Timeline` и `Tween` для управления анимациями без аллокаций. `Tween` хранит состояние интерполяции (`Start`, `End`, `Duration`, `EaseFunc`, коллбэки `OnUpdate`, `OnComplete`). `Timeline.Add` планирует твины; `Timeline.Update(dt)` продвигает все активные твины с 0 bytes/op, 0 allocs/op. Завершённые твины помечаются неактивными и пропускаются. `Timeline.Compact` освобождает мёртвые записи in-place; `Timeline.Clear` сбрасывает таймлайн, сохраняя ёмкость слайса.
- Пример `examples/vfx_demo`: демо в реальном времени с 10 параллельными твинами при 60 fps в течение 2,5 секунд, доказывающее работу системы без утечек памяти.

## [v0.1.1] - 2026-07-27

### Добавлено
- Пакет `core/buffer`: плоская сетка ячеек терминала (`Buffer`) в стиле Data-Oriented Design с выравниванием `Cell` по 16 байт, 0 аллокаций в `Clear()` и безопасным клиппингом координат.
- Пакет `core/diff`: алгоритм сравнения буферов (`Differ`) для вычисления минимального дельта-списка изменений ячеек с 0 аллокаций и 1D-оптимизацией для кэша процессора.
- Пакет `render/ansi`: ANSI-сериализатор (`Renderer`) с поддержкой синхронизированного вывода Mode 2026 и 0 аллокаций в hot path.
- CI/CD пайплайн GitHub Actions (`.github/workflows/ci.yml`) для прогона Go тестов с детектором гонок, `golangci-lint` и анализа кода SonarCloud при пуше/PR в ветку `main`.
- Автоматизированный пайплайн GitHub Release (`.github/workflows/release.yml`), срабатывающий при пуше тегов версий (`v*`).
- Гибридный механизм определения возможностей терминала (`Detect()` и `DetectActive()`) в `internal/term/caps.go` с поддержкой синхронизированного вывода (DECRQM mode 2026) и Kitty keyboard протокола согласно ADR-0002.
- Файл конфигурации SonarCloud (`sonar-project.properties`).

### Исправлено
- Обновлена версия Go в `go.mod` и CI пайплайне на 1.24 для устранения конфликта версий в `golangci-lint`.

## [v0.1.0] - 2026-07-27

### Добавлено
- Инициализация проекта и базовой инфраструктуры.
- Пакет `internal/platform`: абстракции ОС для raw-режима терминала, размера окна, сигналов SIGWINCH и опроса ввода-вывода.
- Пакет `internal/term`:
  - Структура `InputEvent` (tagged union) для передачи событий без аллокаций.
  - Escape-парсер ANSI-последовательностей на конечном автомате (CSI, SS3, SGR мышь, UTF-8, bracketed paste) с 0 аллокаций.
  - Кольцевой буфер (`RingBuf`) с поддержкой степени двойки для чтения stdin без аллокаций.
  - Детектирование возможностей терминала (`Caps`) через окружение и активные запросы DECRQM.
  - Буфер записи (`Writer`) кадра за один системный вызов `write(2)`.
  - Горутина чтения stdin с обработкой таймаута для клавиши ESC.
- Документ `AGENTS.md` с инструкциями для ИИ-агентов.
- Зеркальная мультиязычная структура документации (`docs/en/`, `docs/ru/`, `docs/zh/`).
