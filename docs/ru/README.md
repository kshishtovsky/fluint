Open-source движок терминальных интерфейсов (TUI) для Go, создаваемый **с нуля** с акцентом на плавность анимаций в дискретной сетке, продвинутые VFX (easing, sub-cell рендеринг, переходы) и встроенный UI kit.

## Ключевые особенности

- **Разработка с нуля:** Без зависимостей от `Bubble Tea`, `tcell`, `termbox` или `lipgloss`.
- **Zero-Allocation Hot Path:** Диффинг буферов, рендеринг состояния, диспетчеризация событий и тикеры анимаций не выделяют память (0 аллокаций на кадр).
- **Один системный вызов на кадр:** Сформированный ANSI-поток диффа отправляется строго за один вызов `write(2)` на кадр, предотвращая мерцание (tearing).
- **Продвинутый VFX-инструментарий:** Встроенные кривые плавности (easing), sub-cell примитивы (half-blocks, braille, градиентная плотность) и сглаженные переходы.
- **Чистые зависимости:** Используется только стандартная библиотека и `golang.org/x/sys` для termios/ioctl.
