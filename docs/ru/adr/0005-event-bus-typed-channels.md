# ADR-0005: Типизированные каналы в Event Bus

## Статус
Принято

## Контекст
Передача событий (клавиатура, мышь, ресайз, таймеры) от источников к потребителям.

## Решение
**Типизированные каналы** — отдельный `chan T` на каждый тип события (`chan KeyEvent`, `chan MouseEvent`, `chan struct{}`). Внутренняя транспортировка через `chan InputEvent` (tagged union).

## Обоснование
- Контроль типов на этапе компиляции без интерфейсов и приведений типов.
- Передача структур по значению с 0 аллокаций.
- Незначительный оверхед `select` на 3–5 каналах.
