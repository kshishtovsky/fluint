# ADR-0004: Functional Options для API виджетов

## Статус
Принято

## Контекст
Публичный API виджетов должен быть расширяемым, типобезопасным и идиоматичным для Go.

## Решение
**Functional options** — создание виджетов в виде:
```go
btn := widgets.NewButton("OK",
    widgets.WithWidth(10),
    widgets.WithOnPress(handler),
)
```
Обязательные параметры передаются в конструктор, опциональные — через `WithXxx`.

## Обоснование
- Идиоматичный подход для Go.
- Расширение API без поломки обратной совместимости.
- Строгая проверка обязательных аргументов на этапе компиляции.
