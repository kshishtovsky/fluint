# ADR-0002: Комбо-определение возможностей терминала

## Статус
Принято

## Контекст
Движок должен определять возможности терминала (глубину цвета, поддержку synchronized output, kitty keyboard protocol). Выбор стратегии влияет на таймауты запуска и надежность.

## Решение
**Комбо** — переменные окружения (`$TERM`, `$COLORTERM`, `$TERM_PROGRAM`) для быстрого базового уровня; активные ANSI-запросы (DECRQM для моды 2026, DA1) для продвинутых возможностей с таймаутом и безопасным фоллбеком.

## Обоснование
- Переменные окружения работают моментально с нулевым I/O.
- Активные запросы дают точную информацию о реальных фичах терминала.
- Таймаут и фоллбек гарантируют работу в пайпах и при неразговорчивом терминале.

## Последствия
- Два пути определения (env и активный запрос).
- Реализация: `Detect()` и `DetectActive()` в `internal/term/caps.go`.
