# ADR-0003: Graceful Degradation при ошибках терминала

## Статус
Принято

## Контекст
Ошибки терминала (resize во время кадра, обрыв tty, ошибка записи) должны обрабатываться без паники в render loop (запрещено Доктриной §3.4).

## Решение
**Graceful degradation** — ошибки перехватываются внутренне:
- Resize — пропуск кадра и пересчет на следующем кадре.
- Ошибка записи — уведомление через канал ошибок `chan error`.
- Потеря tty — корректный клинап терминала и завершение.

## Обоснование
- Запрет паники в render loop.
- Канал ошибок не блокирует горячий цикл.
- Гарантированный клинап ресурсов терминала.
